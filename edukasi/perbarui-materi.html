Perbarui materi

Pakai halaman ini setiap kali kamu mengubah, menambah, atau menghapus file materi (.md).

  1. Klik tombol di bawah, lalu pilih folder edukasi.
  2. Periksa daftar materi dan peringatan yang muncul.
  3. Klik Unduh materi.js, lalu taruh file itu di folder edukasi untuk menggantikan yang lama.
  4. Unggah ulang folder ke hosting.
